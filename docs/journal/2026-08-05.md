- **A resume wrinkle the drills multiply by three: persisted binds.** The vocabulary writes harness-allocated ports into workspace `config.yaml` files *inside the world*, so a checkpoint carries them; a resumed run's fixture restart re-reads the old port, and a collision on the resume-day host would surface as live-but-never-ready — classified as a product-surface finding when it is really an environment collision. Worth a disposition before stage 1 settles the process-restart path: re-allocate and rewrite harness-authored bind files at restore time, or accept-and-document with `--clean` as the reset.
